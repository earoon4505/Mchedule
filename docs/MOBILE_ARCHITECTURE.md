# MapleSchedule 모바일 웹 전용 아키텍처 및 데스크톱 차이점 가이드 (MOBILE_ARCHITECTURE.md)

> ⚠️ **[모든 AI 에이전트 및 개발자 필독 경고]**
> 본 프로젝트는 **Windows 데스크톱 앱(Electron)**과 **모바일 반응형 웹(Mobile Web)**을 단일 코드베이스로 동시에 완벽하게 지원합니다.
> 데스크톱과 모바일 환경의 UI/UX 및 작동 방식 차이는 **실수가 아닌 100% 의도된 설계(Intentional Design)**입니다.
> **"데스크톱과 다르다"는 이유로 모바일 전용 로직을 임의로 제거하거나, 데스크톱과 동일하게 통일해 버리는 치명적인 실수를 절대 범하지 마십시오.**

---

## 📌 1. 핵심 철학 (Design Philosophy)
1. **데스크톱 (Electron & PC Web)**:
   - 가로 1280px 이상의 넉넉한 3열(Sidebar - Main - Panel) 풀스크린 뷰.
   - 키보드/마우스 중심, 한눈에 모든 진행률과 캐릭터 정보를 조망하는 대시보드 형태.
2. **모바일 웹 (Mobile Web, `< lg` 즉 1024px 미만)**:
   - 좁은 세로 화면, 한 손 조작 및 터치/스와이프 중심.
   - 3열을 동시에 보여주는 대신 **하단 네비게이션을 통한 명확한 화면 전환 UX** 제공.
   - 브라우저의 동적 주소창 및 하단 툴바, 노치/홈 인디케이터(Safe Area)에 콘텐츠가 가려지지 않도록 전용 여백 보장.

## 📱 2. 데스크톱 vs 모바일 차이점 비교 (차이점 상세 명세)

| 구분 | 데스크톱 환경 (Desktop / `lg` 이상) | 모바일 환경 (Mobile / `lg` 미만) | 설계 의도 (절대 통일 금지) |
| :--- | :--- | :--- | :--- |
| **전체 화면 레이아웃** | **3열 병렬 노출**<br>(사이드바 + 메인 + 패널) | **단일 뷰 전환 노출**<br>(하단 탭바에 따라 1개 뷰만 집중) | 모바일에서 3열을 억지로 노출하면 글자가 겹치고 조작 불가 |
| **네비게이션** | 상단 타이틀바 / 사이드바 직접 클릭 | **화면 최하단 3단 고정 탭바**<br>(`MobileBottomNav.tsx`) | 한 손 엄지손가락으로 쉽게 화면 전환 |
| **캐릭터 목록 조작** | 마우스 호버로 순서 이동 및 삭제 버튼 노출 | 상단 **`[편집]` 토글 버튼** 클릭 시 순서 이동/삭제 버튼 노출 | 터치 화면에서는 마우스 호버(Hover)가 불가능하므로 편집 모드 필수 |
| **캐릭터 선택 후 동작** | 우측 메인 영역에 선택 캐릭터 상세 즉시 갱신 | 카드 탭 시 **캐릭터 상세 화면으로 자동 전환** + 상단 `[← 캐릭터 목록]` 복귀 버튼 노출 | 모바일에서는 캐릭터를 고른 뒤 즉시 할 일을 체크할 수 있도록 이동 |
| **우측 패널 (진행 현황)** | 몬스터파크/에픽던전 + 달성률 통계 **동시 노출** | 하단 탭에 따라 **`[계정 컨텐츠]` 뷰**와 **`[진행 현황]` 뷰**로 명확히 분리 | 작은 화면에서 스크롤 압박을 줄이고 필요한 정보에 빠르게 접근 |
| **우측 패널 상단** | 상단에 캐릭터 선택 요약 헤더 및 별표 버튼 표시 | 상단 중복 헤더 숨김 (`lg:hidden`), 맨 위부터 몬파/에픽던전 시원하게 노출 | 세로 공간이 부족한 모바일에서 불필요한 중복 정보를 제거하여 광활한 뷰포트 확보 |
| **스케줄 설정 탭바 (`ContentConfigModal`)** | 데스크톱 규격 (`max-w-4xl`, `h-[720px]`, `text-xs`, `px-3 py-1.5`) | **가로 스와이프 스크롤** + 모바일 맞춤 크기 (`text-[11px]`, `py-1`, `leading-none`) | 탭이 다음 줄로 꺾이지 않고 1줄로 유지되며, 버튼 상하 테두리가 잘리지 않도록 정밀 패딩 적용 |
| **캐릭터 검색 인풋 (`CharacterSearchModal`)** | 모달 열릴 때 검색창 `autoFocus` 활성화 | **`autoFocus` 비활성화** + 폰트 16px (`text-base`) | 모바일에서 모달을 열자마자 키보드가 불쑥 튀어나와 화면을 가리거나 iOS가 화면을 강제 줌(Zoom)하는 현상 원천 차단 |
| **스크롤바 표시** | 얇은 스크롤바 또는 기본 스크롤바 | **스크롤바 완전 숨김 (`no-scrollbar`)**<br>(터치 스크롤 100% 정상 작동) | 좁은 화면에서 스크롤바가 콘텐츠나 체크박스를 가리는 시각적 노이즈 제거 |
| **하단 여백 (Padding)** | 일반적인 패딩 (`pb-3` 등) | **안전 영역 패딩** (`pb-[calc(env(safe-area-inset-bottom,0px)+5rem)]`) | 모바일 브라우저의 하단 툴바나 홈 바에 마지막 카드가 가려지는 현상 100% 방지 |

## 🛠️ 3. 모바일 전용 컴포넌트 및 핵심 파일 목록

1. **`src/components/common/MobileBottomNav.tsx`**:
   - 모바일 최하단 고정 네비게이션 컴포넌트.
   - 클래스: `lg:hidden fixed bottom-0 left-0 right-0 z-40 bg-white/95 dark:bg-slate-900/95 backdrop-blur-md border-t ...`
   - **주의**: 데스크톱(`lg:`)에서는 절대 나타나지 않아야 합니다.

2. **`src/components/character/CharacterSidebar.tsx`**:
   - 모바일 모드 분기: `isMobileView && mobileActiveTab !== 'characters'` 일 때 `hidden lg:flex`로 처리.
   - 모바일 편집 모드 토글: `btn-mobile-character-edit-mode`.

3. **`src/components/character/ProgressPanel.tsx`**:
   - 모바일 모드 분기: `mobileActiveTab === 'account'` (몬파/에픽 전용), `mobileActiveTab === 'progress'` (진행률 전용).
   - 데스크톱에서는 이 모드 분기와 무관하게 전체 패널이 정상 노출됩니다.

4. **`src/components/tasks/ContentConfigModal.tsx`**:
   - 탭 네비게이션 가로 스크롤: `overflow-x-auto no-scrollbar touch-pan-x`.
   - 데스크톱 클래스(`sm:px-3 sm:py-1.5 sm:text-xs`)와 모바일 클래스(`px-2.5 py-1 text-[11px]`)가 공존하므로 임의로 합치지 마십시오.

5. **`src/components/character/CharacterSearchModal.tsx`**:
   - 검색창의 모바일 폰트 크기 `text-base sm:text-xs` 유지 (16px 미만일 경우 iOS 사파리 자동 확대 버그 방지).

## ⚠️ 4. 향후 작업 시 절대 금지 사항 (Strict Prohibitions)
1. **"모바일 화면 전환 방식을 데스크톱처럼 3열로 합치자"는 식의 수정 금지**:
   - 모바일의 3단 하단 탭(`MobileBottomNav`)은 좁은 화면을 위한 최선의 UX입니다.
2. **모바일 여백(`pb-[calc(...) + 5rem]`) 임의 축소 금지**:
   - 축소 시 모바일 브라우저 하단 툴바 뒤로 캐릭터 추가 버튼이나 마지막 보스 카드가 파묻히게 됩니다.
3. **데스크톱 스타일과 모바일 반응형 스타일을 동일하게 통일하려는 시도 금지**:
   - 반드시 `sm:`, `lg:` 등 Tailwind 중단점(Breakpoint)을 사용하여 데스크톱의 안정적인 뷰와 모바일의 편의성을 분리 유지해야 합니다.
