# 🍁 환산 (MapleScouter 연동 명세 및 아키텍처)

이 문서는 **메케줄(MapleSchedule) 데스크톱 앱 전용 환산 기능**의 기술 아키텍처, 데이터 흐름, 웹 완전 격리(트리쉐이킹) 원칙 및 상세 명세를 기록합니다.

---

## 1. 개요 및 목적
* **목적**: 메이플스토리 데스크톱 앱(Electron)에서 캐릭터의 환산 스펙 지표(환산 주스탯, 헥사 환산 주스탯, 보스 배율)를 손쉽게 확인하고 비교할 수 있도록 연동합니다.
* **사용 범위**: 
  - **Windows 데스크톱 앱**: 환산 페이지(`ConversionPageView`), 공식 60개 보스 연산 엔진, 메이플스카우터 직접 크롤링/조회 기능 100% 탑재.
  - **공개 웹사이트(Vercel 등)**: 환산 관련 일체의 코드, UI 버튼, 문자열, 번들을 **컴파일 타임에 100% 완전 도려내어(Tree-Shaking) 0바이트로 격리**.
* **버전 분리**: 본 환산 기능은 정식 릴리즈 스케줄러 기능과 독립적으로 격리되어 안전하게 관리됩니다.

---

## 2. 핵심 원칙 및 운영 정책

### 1) 웹 빌드 시 환산 기능 완전 도려내기 (Tree-Shaking 격리)
* **환경 플래그 (`vite.config.ts`)**:
  - `BUILD_TARGET === 'web'` 또는 Vercel 환경 감지 시 `__DESKTOP_SCOUTER_ENABLED__`를 `false`로 주입합니다.
  - `ConversionPageView` 컴포넌트를 빈 스텁(`ConversionPageView.web.tsx`, `return null;`)으로 Alias 교체합니다.
* **UI 및 코드 제거 (`src/App.tsx`)**:
  - 상단 헤더의 `환산` 버튼 및 본문 렌더링 영역이 `{__DESKTOP_SCOUTER_ENABLED__ && (...)}`로 감싸져 있어, 번들러가 빌드할 때 해당 코드와 텍스트를 흔적도 없이 삭제합니다.

### 2) 자동 갱신 완전 배제 (100% 사용자 수동 호출)
* 메케줄의 기본 2분 주기 자동 동기화 타이머에서 제외됩니다.
* 상단 전체 새로고침 버튼(`handleSyncAll`) 및 캐릭터 탭 전환 시에도 호출되지 않습니다.
* 오직 사용자가 환산 페이지에서 명시적으로 **[환산 갱신]** 버튼을 클릭했을 때만 1회 단발성으로 호출합니다.

### 3) 3단계 고속 크롤링 & 연산 엔진 아키텍처 (`electron/main.cjs`)
1. **1단계 (로컬 Express 프록시 캐시)**: `http://127.0.0.1:3000/api/scouter/stats` 초고속 조회 (0.2초 이내 무오차 계산)
2. **2단계 (메이플스카우터 공식 데이터 API & 공식 연산 엔진)**: 
   - 4차 다항식 및 큐빅 스플라인(`evaluateSpline`), 방무/포스/레벨 반감 정확 반영
   - 도핑/비약 효율 배율(`specEfficiency`, `elixir`, 20분 도핑) 반영
3. **3단계 (Chromium 가상 브라우저 fallback)**:
   - `new BrowserWindow({ show: false })`로 보이지 않는 가상 크롬 창을 띄워 메이플스카우터 웹페이지 DOM에서 실시간 렌더링 결과를 안전하게 보조 파싱 후 즉시 메모리 해제(`destroy()`).

## 3. 가져올 대상 데이터 명세

* **환산 주스탯**: 캐릭터의 종합 스펙 환산 수치
* **헥사 환산 주스탯**: 6차 헥사 코어 강화가 반영된 환산 수치
* **전투력**: 공식 넥슨 인게임 전투력 지표
* **보스 배율**: 메이플스카우터 공식 60개 보스(유피테르, 최초의 대적자, 발드릭스, 림보, 카링 등 최신 심연/그란디스 보스 포함) 상대 딜 배율

---

## 4. UI/UX 디자인 및 보스 카드 레이아웃

* **3대 핵심 지표 카드**: 선택된 캐릭터의 아바타, 전투력, 환산 주스탯, 헥사 환산 수치를 상단에 한눈에 배치.
* **보스 카드 그리드 (`ConversionBossList`)**:
  - 가로가 긴 직사각형 카드 형태, 반응형 3열 그리드 배치 (`grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`).
  - [좌측]: 보스 이미지 (`MapleIcon` 로컬 고화질 에셋 우선 연동, 신규 보스 시 원본 아이콘 자동 폴백).
  - [우측 상단]: 난이도 배지 (익스트림/카오스/하드/노말 등, 챔피언-주황색, 데스티니-블랙 앤 화이트).
  - [우측 중간]: 보스 이름 (최신 명칭 정규화).
  - [우측 하단]: 보스 배율 큰 숫자 (각 상태별 컬러와 1:1 완벽 일치 매칭).
* **신규 보스 자동 확장**: 향후 신규 보스 출시 시 메케줄 코드 수정 없이도 [환산 갱신] 한 번으로 새로운 보스 카드와 배율이 100% 자동 생성되는 유연한 데이터 매핑 구조 구축.

## 5. 기술 아키텍처 및 데이터 흐름도

```
[사용자가 '환산 갱신' 버튼 클릭]
          ↓
[Renderer Process (React)]
          ↓ window.electronAPI.fetchScouterStats(characterName)
[Main Process (electron/main.cjs)]
          ↓
[1단계: 로컬 캐시 / 2단계: 메이플스카우터 공식 연산 엔진 / 3단계: Chromium 가상 브라우저]
          ↓
[결과 데이터 IPC 반환 및 로컬 저장 (storage.json / localStorage)]
          ↓
[환산 페이지 뷰(ConversionPageView) 실시간 반영]
```

## 8. 🔒 지적재산권 보호 및 비공개(Private) 저장소 영구 유지 보안 규칙
* **환산 코드 완전 은닉 (외부 유출 원천 차단)**:
  - 1차 방어선: **웹사이트(`mchedule.com`) 빌드 시 환산 코드 100% 트리쉐이킹(Tree-shaking)** 처리되어 웹 번들에는 단 한 글자의 환산 코드도 존재하지 않습니다.
  - 2차 방어선: **GitHub 저장소(`earoon4505/Mchedule`) 영구 비공개(Private)** 유지로 외부인이 깃허브 소스코드를 절대 열람할 수 없습니다.
* **비공개 릴리즈 자동 업데이트 & 토큰 수칙**:
  - 데스크톱 앱 내 Base64 암호화된 토큰으로 비공개 릴리즈를 자동 다운로드합니다.
  - **절대 공개(Public)로 전환 금지**: 공개 전환 시 깃허브 스캐너가 토큰을 강제 만료시켜 업데이트가 마비됩니다.
  - **만약 공개 전환 시**: 공개 상태에서는 토큰을 넣고 푸시할 수 없으며, 새 토큰 재발급 후 비공개로 되돌려 재탑재해야 합니다.
