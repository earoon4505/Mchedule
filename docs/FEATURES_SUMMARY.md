# 📋 3. 메케줄 기능 명세 요약서 (FEATURES_SUMMARY.md)

이 문서는 **MapleSchedule (메케줄)** 애플리케이션이 제공하는 주요 기능과 모듈별 동작 방식을 요약합니다.

---

## 1. 캐릭터 관리 및 넥슨 Open API 연동
- **다중 계정(API Key) 지원**: 여러 개의 넥슨 Open API 키를 등록하고 각각 별칭(예: 본계정, 부계정 등)을 부여하여 계정별 캐릭터들을 통합 관리.
- **캐릭터 원클릭 검색 및 등록**:
  - API 키를 선택하고 넥슨 공식 캐릭터 목록 및 캐릭터 기본 정보(`character/basic`)를 조회하여 간편하게 등록.
  - 레벨에 맞춘 일일/주간 기본 퀘스트 및 보스 프리셋 자동 활성화.
- **인게임 스케줄러 자동 동기화**:
  - 넥슨 Open API의 인게임 스케줄러 데이터(`scheduler_info`)를 분석하여 게임 내에서 완료된 퀘스트와 보스를 자동으로 체크.
  - 수동 새로고침 버튼 및 2분(설정 가능) 주기 백그라운드 자동 동기화 지원.
- **월드리프(서버 이전) 캐릭터 자동 치유 (Self-Healing)**:
  - 인게임에서 월드리프를 진행하여 기존 `ocid`가 만료되었을 때, 닉네임 기반으로 최신 OCID를 자동 재발급받아 기존 완료 기록과 설정을 100% 보존.

## 2. 스케줄 및 콘텐츠 관리

### 2.1 일일 콘텐츠
- **일일 퀘스트**: 소멸의 여로, 츄츄 아일랜드 등 아케인리버/그란디스 심볼 퀘스트.
- **일일 보스**: 노말/카오스 자쿰, 힐라, 매그너스 등 (월~일요일 목요일 주기 요일별 처치 히스토리 로그 지원).
- **몬스터파크 & 몬스터파크 익스트림**: 캐릭터별 레벨 맞춤 일일 수행 체크.

### 2.2 주간 및 월간 콘텐츠
- **주간 보스**: 이지 루시드부터 익스트림 진 힐라, 칼로스, 카링, 림보까지 난이도별 결정석 가격 및 클리어 상태 관리 (목요일 자정 리셋).
  - 캐릭터별 주간 보스 목표 마리수(Threshold, 기본 12마리) 설정 지원.
- **주간 퀘스트**: 샤레니안의 지하 수로, 플래그 레이스, 무릉도장, 주간 미션 등.
- **에픽 던전**: 하이마운틴, 앵글러 컴퍼니, 악몽 선경, **아우룸 레기스(290Lv 신규)** 클리어 관리.
- **검은 마법사**: 매월 1일 자정 리셋되는 월간 보스 전용 카드 및 난이도(하드/익스트림) 선택 지원.

### 2.3 커스텀 스케줄
- 사용자가 직접 타이틀, 주기(일일, 특정 요일 복수 선택, 매월 N일), 리셋 시각을 지정하여 유연한 개인 스케줄 추가 가능.

## 3. 다계정 계정 공통 컨텐츠 시스템
- **계정별 독립 격리**: 몬스터파크 및 에픽 던전(하이마운틴, 앵글러, 선경, 아우룸 레기스) 등 계정 공유 컨텐츠 체크 시, 동일 계정에 속한 캐릭터들만 격리 업데이트하여 다른 계정 데이터 오염 원천 차단.
- **메인 화면 별칭 네비게이션 바**:
  - 다계정 환경에서 '계정 컨텐츠' 헤더 아래에 API 키 등록 순서대로 별칭 필(Pill) 탭 노출.
  - 마우스 휠 가로 스크롤 지원 및 원클릭 계정 전환.

## 4. PiP (Always-on-Top / Picture-in-Picture) 듀얼 모드
- **데스크톱 독립 PiP (Electron)**: 게임 화면 위에 상시 떠 있는 최상위 윈도우(`alwaysOnTop: true`), 투명도 조절, 마우스 통과 및 크기 자동 조절 연동.
- **웹 오버레이 PiP**: 브라우저 화면 우측/좌측 상하단에 떠 있는 플로팅 위젯.
- **세 가지 뷰 스타일**:
  1. *세로형(Vertical)*: 캐릭터 카드가 수직으로 정렬된 슬림 레이아웃.
  2. *가로형(Horizontal)*: 캐릭터 카드가 가로로 나열된 파노라마 레이아웃.
  3. *프로필 축소 모드(Only Avatar)*: 아바타 사진과 완료 상태만 극도로 미니멀하게 노출.
- **PiP 계정 인디케이터**: 복수 계정 환경에서 비활성 계정은 미니멀한 원형 점, 활성 계정은 부드럽게 늘어나는 별칭 필(Pill)로 확장되어 시각적 직관성 제공.

## 5. UI/UX 및 모션 애니메이션
- **물리 기반 스프링 애니메이션 (`motion/react`)**: 스위치 토글, PiP 카드 추가/제거 및 완료 숨김 전환, 계정 탭 확장에 끊김 없는 유기적 모션 적용.
- **초기화 임박 알리미 (Notifier)**: 일일(자정), 주간(목요일) 초기화 전 미완료 스케줄을 보유한 캐릭터를 감지하여 뱃지 및 모달 알림.
- **넥슨 서버 상태 및 점검 자동 감지 시스템**:
  - `503 Service Unavailable`: "API 점검 안내" 배너 자동 노출 (넥슨 Open API 서버 자체 점검).
  - `500 Internal Server Error`: "게임 서버 점검/오류" 배너 자동 노출 (목요일 정기 점검 또는 인게임 서버 지연).
  - 배너 우측 [상태 재확인] 및 [✕ 닫기] 기능 지원. 점검 중에도 수동 체크 및 로컬 데이터는 100% 정상 보존.

## 6. 모바일 웹 전용 버전 및 반응형 지원 체계 (v1.0.6)
- **하단 고정 모바일 3단 네비게이션 (`MobileBottomNav.tsx`)**:
  - 모바일(화면 폭 `lg` 미만) 접속 시 화면 하단에 `[캐릭터]`, `[계정 컨텐츠]`, `[진행 현황]` 고정 네비게이션 제공.
  - 데스크톱(Electron 앱 및 PC 웹 브라우저)에서는 `lg:hidden`으로 완전히 숨겨져 기존 3단 데스크톱 레이아웃 100% 무영향 보존.
- **캐릭터 목록 뷰 및 전환 UX (`CharacterSidebar.tsx`)**:
  - 상단 닉네임 목록/계정 필터 및 캐릭터 카드 세로 스크롤 최적화 (`touch-pan-y`, `overscroll-contain`, 안전 영역 패딩).
  - 모바일 카드 탭 시 캐릭터 상세 화면으로 원활하게 자동 이동하며, 상단 `[← 캐릭터 목록]` 복귀 버튼 제공.
  - 상단 우측 `[편집]` 토글 버튼을 통해 모바일에서도 캐릭터 순서 변경 및 삭제 모드 완벽 지원.
- **계정 컨텐츠 및 진행 현황 모바일 탭 분기 (`ProgressPanel.tsx`)**:
  - `mobileMode`에 따라 `[계정 컨텐츠]` 선택 시 몬스터파크/에픽던전 전용 뷰, `[진행 현황]` 선택 시 달성률/통계 전용 뷰로 시인성 극대화.
  - 불필요한 중복 헤더 및 별표 버튼을 정리하여 몬스터파크와 에픽 던전이 맨 위부터 넓고 쾌적하게 보이도록 최적화.
- **모바일 브라우저 하단바 및 안전 영역(Safe-Area) 완벽 대응**:
  - Safari, Chrome, 삼성 인터넷 등 모바일 브라우저의 동적 URL 주소창/하단 툴바에 콘텐츠가 가려지지 않도록 `viewport-fit=cover` 및 `pb-[calc(env(safe-area-inset-bottom,0px)+5rem)]` 적용.
- **모바일 폼 및 모달 최적화**:
  - `CharacterSearchModal` 진입 시 `autoFocus`를 배제하고 인풋 글자 크기를 16px(`text-base`)로 조정하여 모바일 OS(iOS 등)의 화면 자동 확대(Zoom-in) 및 원치 않는 가상 키보드 팝업 방지.
  - `ContentConfigModal`(스케줄 설정) 탭 네비게이션은 가로 스와이프 스크롤을 지원하며, 모바일(`sm:` 미만)에서 탭 버튼 텍스트(`text-[11px]`)와 패딩(`py-1`)을 정밀 조정하여 상하 잘림 없이 완벽 표시.
