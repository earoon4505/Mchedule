## 🚀 주요 변경 및 비공개(Private) 저장소 자동 업데이트 연동

### 1. 비공개(Private) 저장소 자동 업데이트(`electron-updater`) 연동
- **배경**:
  - 전투력 및 환산 관련 기능의 보안 및 비공개 배포를 위해 GitHub 저장소(`earoon4505/Mchedule`)를 비공개(Private)로 전환함에 따라, 패키징된 데스크톱 앱에서 지인들이 별도 인증 절차 없이 원클릭으로 최신 버전을 다운로드 및 자동 패치할 수 있도록 업데이트 시스템 개편.
- **조치 사항**:
  1. **`package.json`**:
     - `build.publish` 블록에 `"private": true` 속성을 추가하여 `electron-builder`가 비공개 저장소 전용 배포 메타데이터(`app-update.yml`)를 정상 생성하도록 설정.
  2. **`electron/main.cjs`**:
     - GitHub 읽기 전용 Personal Access Token(`GITHUB_READ_TOKEN`, Contents: Read-only)을 연동.
     - `autoUpdater.setFeedURL`에 `private: true` 및 `token`을 등록하여 `electron-updater` 내부의 `PrivateGitHubProvider`를 활성화.
     - 이를 통해 앱 실행 시 백그라운드에서 비공개 저장소의 최신 Releases 정보를 안전하게 조회하고 자동으로 다운로드 및 설치 승인 플로우 연동.
