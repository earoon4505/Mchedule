# 🚀 메케줄 v1.0.4 업데이트 상세 내역 (docs/changelogs/v1.0.4.md)

이 문서는 **MapleSchedule (메케줄) v1.0.4** 버전에서 확립된 Vercel 웹 정적 호스팅 대응 및 듀얼 아키텍처 방어 로직을 기록합니다.

---

### 1. 정적 웹 호스팅(Vercel) 넥슨 API 직접 통신 구축
- **문제 해결**: Vercel 배포 시 백엔드 Node.js 서버가 없어 `/api/...` 요청 시 `index.html`이 반환되며 JSON 파싱 에러(`Unexpected token '<'`)가 발생하던 치명적 오류 해결.
- **듀얼 구조 구축**:
  - Electron 데스크톱: 로컬 Express 프록시 우선 호출.
  - Vercel 웹 환경: 브라우저가 직접 `https://open.api.nexon.com` 호출.
  - 모든 응답에 `contentType.includes('application/json')` 방어 가드 추가.

---

### 2. 캐릭터 아바타 이미지 URL 듀얼 처리
- Electron 데스크톱: CORS 회피 및 디스크 캐싱을 위한 `/api/proxy/image` 사용.
- Vercel 웹 환경: 프록시가 없으므로 넥슨 공식 CDN 원본 URL 직접 반환(엑박 원천 방지).

---

### 3. 인게임 스케줄러 동기화 클리어 기록 보호 2중 가드
- 넥슨 Open API 서버가 일시적인 지연이나 빈 배열(`[]`)을 응답하더라도, 유저가 기존에 체크해둔 클리어 기록(일일/주간/보스)이 일괄 초기화(false)되지 않도록 방어하는 2중 보호 가드(`rawDaily.length === 0` 가드) 구현.

---

### 4. 웹 환경 캐릭터 등록 시 프로필 사진 보강
- 넥슨의 `/character/list` API 응답에 캐릭터 아바타 이미지가 없는 한계를 극복하기 위해, 웹 환경에서도 상위 캐릭터에 대해 `/character/basic`을 직접 호출하고 `sessionStorage`에 캐시하는 보강 파이프라인 구축.
