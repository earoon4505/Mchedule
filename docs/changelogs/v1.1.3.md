# 🚀 메케줄 v1.1.3 업데이트 내역 (docs/changelogs/v1.1.3.md)

이 문서는 **MapleSchedule (메케줄) v1.1.3**의 주요 변경 사항 및 작업 내역을 명확하게 기록합니다.

---

## 📌 v1.1.3 마일스톤 (2026년 10월)

### 1. 주간 보스 '유피테르' 난이도 정정 (익스트림 ➔ 하드)
1. **유피테르 난이도 규격 정정**:
   - 주간 보스 목록 및 맞춤 설정 모달에서 유피테르 상위 난이도를 기존 '익스트림'에서 **'하드'**(`boss_hard_jupiter`)로 정상 변경.
   - [노말 / 하드] 2종 난이도 체계 확립.
2. **하위 호환성 및 기존 캐릭터 데이터 무손실 보호**:
   - 기존에 `boss_extreme_jupiter`를 선택하거나 클리어했던 사용자의 데이터가 손실되지 않도록 `ALL_TASKS_MAP` 및 보스 정렬 함수(`sortBossIdsByStandardOrder`)에서 `boss_hard_jupiter`로 자동 매핑 보존.
   - 넥슨 Open API 인게임 스케줄러 동기화(`findBossTaskId`)에서 '익스트림' 또는 '하드' 키워드 모두 `boss_hard_jupiter`로 완벽 호환 파싱 지원.

### 2. 애플리케이션 버전 판올림 (v1.1.3)
1. **버전 단일 소스 동기화**:
   - `package.json`: 버전 `1.1.2` ➔ `1.1.3` 판올림.
   - `src/constants/version.ts`: `APP_VERSION = '1.1.3'` 갱신.
   - `src/App.tsx`: 자동 업데이트 리스너 기본 버전 폴백 갱신.
   - `BUILD_INSTALLER_GUIDE.md`: `maple-schedule-setup-1.1.3.exe` 및 `메케줄 1.1.3.exe` 배포 안내 동기화.
