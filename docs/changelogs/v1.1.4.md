# 메케줄 (MapleSchedule) v1.1.4 변경 내역 (Changelog)

## 🚀 주요 변경 및 버그 해결 사항

### 1. 에스페라 일일 퀘스트 및 프로텍트 에스페라(주간) 인게임 동기화 매핑 정밀 해결
- **문제 원인 분석**:
  1. **주간 퀘스트의 일일 퀘스트 오인식 및 덮어쓰기**:
     - `KEYWORD_TASK_MAP`에서 단순 `'에스페라'` 키워드로 인해 주간 퀘스트인 `프로텍트 에스페라`가 일일 퀘스트(`daily_arcane_espera`)로 오인식되어 완료 상태가 덮어써지는 문제.
  2. **넥슨 공식 `is_cleared` 필드 및 클리어 플래그 누락**:
     - 넥슨 Open API 스케줄러 응답의 공식 완료 필드인 `is_cleared: true`가 `evaluateContentProgress`의 `hasCompleteFlag` 목록에서 누락되어 있어, API가 완료를 전달해도 미완료로 처리되는 심각한 결함 발견.
  3. **주간 컨텐츠 탭의 지역명 단독 표기(`weekly_contents`) 미대응**:
     - 인게임 스케줄러에서 주간 퀘스트가 `[주간] 에스페라` 또는 `에스페라`로 올 때 `weekly_arcane_espera`의 키워드에 매칭되지 않고 누락되는 문제.
  4. **퀘스트 히스토리(`/character/quest-history`) 연동 누락**:
     - 인게임 스케줄러 창(단축키 `\`)에 등록하지 않았거나 스케줄러 API가 지연될 때, 퀘스트 히스토리의 완료 내역을 주간 아케인 퀘스트에 반영하지 않던 문제.

- **해결 조치**:
  1. **넥슨 공식 `is_cleared`, `clear_status`, `clear` 필드 완벽 추가**:
     - `evaluateContentProgress`의 `hasCompleteFlag`에 `is_cleared`를 포함한 모든 넥슨 응답 규격을 전수 추가.
     - 주간 아케인 퀘스트 완료 판정에 `isBossItemCompleted(item)`, `nowCount >= 1`, `remain_count === 0` 검사를 추가하여 100% 인식.
  2. **주간 컨텐츠(`isWeeklyHint: true`) 전용 아케인리버 직결 매핑 구축**:
     - `weekly_contents` 파싱 시 `norm`에 `에스페라` 또는 `프로텍트`가 포함되면 무조건 `weekly_arcane_espera`로 100% 직결 매칭.
     - 여로, 츄츄, 레헬른, 아르카나, 모라스 등 다른 주간 아케인 퀘스트도 동일하게 직결 매칭 보강.
  3. **퀘스트 히스토리(`/character/quest-history`) 2중 확정 연동**:
     - 넥슨 퀘스트 히스토리에서 이번 주(목요일 리셋 이후) 완료된 프로텍트 에스페라 및 주간 아케인 퀘스트 완료 기록을 실시간 감지하여 자동 체크 반영.
  4. **클리어 데이터 보존 가드**:
     - 인게임에서 실제로 클리어한 주간 퀘스트는 `enabledTaskIds`에 설령 누락되어 있더라도 버리지 않고 완료 상태를 확실하게 보존.
