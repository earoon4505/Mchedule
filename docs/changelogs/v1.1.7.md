## 🚀 주요 변경 및 비공개 토큰 갱신

### 1. 비공개 저장소(Private) GitHub Personal Access Token 갱신
- **배경**:
  - 기존 토큰이 GitHub Push Protection(Secret Scanning)에 의해 일시 무효화되었던 문제를 해결하기 위해, 새로 발급된 정상 Fine-grained PAT를 연동.
- **조치 사항**:
  - `electron/main.cjs`의 `GITHUB_READ_TOKEN`을 신규 토큰의 Base64 인코딩 값으로 교체.
  - 이를 통해 비공개 저장소 상태에서도 Releases API를 정상 인증(`200 OK`)하고, 향후 모든 버전의 자동 다운로드 및 패치가 중단 없이 동작하도록 보장.
