**적용 대상**: Windows 데스크톱 앱 (Electron) 및 공식 웹 애플리케이션

## 📌 주요 업데이트 요약

### 1. 📂 '전체' 탭 섹션 펼침/접힘 상태 영구 기억
* **사용자 맞춤 섹션 상태 유지 (`mapleschedule_section_collapsed_v1`)**:
  - `'전체'` 탭 내 6개 섹션(`일일 컨텐츠`, `일일 보스`, `주간 컨텐츠`, `주간 보스`, `검은 마법사`, `커스텀`)의 펼침/접힘 상태를 `localStorage`에 자동 저장합니다.
  - 다른 캐릭터로 전환하거나 개별 탭에 다녀온 뒤, 또는 앱/브라우저를 다시 실행해도 사용자가 마지막으로 설정해 둔 펼침/접힘 상태가 그대로 유지됩니다.
  - 개별 컨텐츠 탭(`일일`, `주간`, `보스`, `커스텀`)으로 이동할 때는 항상 목록이 펼쳐진 상태로 표시되어 즉시 확인이 가능합니다.

### 2. 🎨 선택형 라이트·다크 화면 테마 프리셋 및 메인 컬러 버튼 선택 지원
* **라이트 모드 프리셋 2종 지원 (`lightTheme: 'classic' | 'cream'`, 기본값: `화이트`)**:
  - **화이트 (`classic`, 기본)**: 상단 헤더의 라이트/다크 전환 버튼 시 기본으로 유지되는 깔끔한 화이트·슬레이트 톤(`#F8FAFC` / `#FFFFFF`).
  - **베이지 (`cream`)**: 눈의 피로를 줄여 주는 따뜻한 크림 베이지 톤(`#FBF3EB` / `#FCF6EF` / `#FFFDFB`, 내부 요소 `#F8EDE1` / `#F5E8DA` / `#DEC8B3`).
* **다크 모드 프리셋 2종 지원 (`darkTheme: 'deep' | 'classic'`, 기본값: `딥 차콜`)**:
  - **딥 차콜 (`deep`, 기본)**: 메인 배경(`#0B0E14`) → 헤더·사이드바(`#111620`) → 카드(`#171E2C`) → 보조 버튼·게이지(`#20293B`)의 4단 명도 계층이 적용된 딥 차콜 다크 테마.
  - **네이비 (`classic`)**: 개편 이전의 슬레이트 네이비 톤(`#020617` / `#0F172A` / `#1E293B`) 다크 테마.
* **설정 > 화면 테마 UI 개편 및 원클릭 토글 연동**:
  - 설정 모달의 **화면 테마** 상단 우측에 해/달 아이콘이 담긴 토글 버튼을 배치(하단 설정 토글들과 우측 위치 정렬)하고, 통합 카드 내 좌측 `라이트`(화이트·베이지) / 우측 `다크`(딥 차콜·네이비) 컬러 버튼을 구분 배치했습니다.
  - 현재 다크 모드 여부와 무관하게 저장된 라이트·다크 프리셋이 모두 주황 테두리로 표시되며, 상단 헤더 및 설정 토글 전환 시 마지막으로 선택한 프리셋으로 즉시 전환됩니다.

### 3. 🌙 다크 모드 호버·시인성 버그 수정 및 테마 토큰 통일
* **다크 모드 호버 번쩍임 및 가독성 개선**:
  - 캐릭터 카드 및 웹 PiP 하단 현황 뱃지(`일보`, `주보`, `일일`, `주간`) 호버 시 `dark:hover:bg-...` 누락으로 밝은 파스텔색이 튀던 문제를 해결했습니다.
  - 6개 스케줄 섹션 접기/펼치기 버튼(`slate-750`) 및 설정 모달 백업/복원 버튼(`slate-850`)의 미적용 호버 클래스를 유효한 다크 테마 토큰으로 수정했습니다.
  - 미등록 뱃지(`검마 -`, `커스텀 -`) 및 PiP 다계정 비활성 점의 어두운 배경 위 시인성을 개선했습니다.
  - 캐릭터 아바타(`CharacterAvatar`) 기본 배경/테두리와 사이드바·PiP 창의 미완료 알림 강조(`alert-pulse-red`) 다크 배경을 테마 토큰(`bg-th-pill`, `dark:bg-th-card`)으로 통일했습니다.

### 4. 🪟 PiP 및 전체 모달·설정·약관·가이드 테마 토큰 일체화
* **CSS 변수 기반 멀티 테마 토큰(`--th-*`) 및 전체 화면 일체화**:
  - 메인 대시보드, 좌·우 사이드바, 모든 스케줄 카드, 데스크톱 독립 PiP 창(`StandalonePiPView`) 및 웹 인앱 PiP(`PiPOverlay`), 설정(`SettingsModal`), 공지사항(`NoticeModal`), 진행 현황 및 계정 컨텐츠 편집(`ProgressPanel`), 캐릭터 추가(`CharacterSearchModal`), API 관리/안내(`ApiKeyModal`, `ApiGuideModal`), 스케줄·커스텀 모달(`ContentConfigModal`, `CustomTaskModal`, `CustomTaskEditModal`), 알림·업데이트(`IncompleteScheduleAlertModal`, `UpdateModal`), 이용약관·개인정보·가이드 모달 및 독립 페이지(`LegalModal`, `GuideModal`, `/guide`, `/terms`, `/privacy`) 전체가 선택한 라이트/다크 프리셋과 100% 연동됩니다.
  - 독립 웹페이지(`/guide`, `/terms`, `/privacy`) 직접 접속 및 새로고침 시에도 저장된 다크 모드 및 테마 프리셋이 즉시 DOM에 동기화되며, Electron PiP 창의 투명 배경 처리는 100% 보존됩니다.

### 5. 🔑 API 등록·목록 및 발급 가이드 창 UX 개선
* **API 등록 탭 레이아웃 및 입력 흐름 정비**:
  - `API 키 (필수)` 입력란을 상단, `별칭 (선택)` 입력란을 하단으로 배치하고 라벨 폰트 크기와 굵기를 키워 시인성을 높였습니다.
  - `API 발급 방법` 버튼(좌)과 `넥슨 Open API 바로가기` 버튼(우)을 배치하고, `API 발급 방법` 버튼에 글자 선명도를 유지한 주황 링 펄스 효과(`.api-guide-pulse`)를 적용했습니다.
  - 4개 영역(API 키 · 별칭 · 등록 버튼 · 하단 버튼)을 세로 균등 배분(`justify-between`)하고 우측 스크롤바를 숨겨 불필요한 여백과 상하 흔들림을 제거했습니다.
* **API 목록 빈 상태 및 가이드 5단계 개선**:
  - API 목록이 비어 있을 때 회색 여백과 점선 박스를 제거해 테마 카드 배경 위에 중앙 정렬되도록 수정했습니다.
  - `ApiGuideModal` 5단계에서 6번 등록 사진을 설명 문구 및 URL 복사 칸의 오른쪽으로 이동해 가독성을 높였습니다.
