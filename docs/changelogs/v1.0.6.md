# 🚀 메케줄 v1.0.6 업데이트 내역 (docs/changelogs/v1.0.6.md)

이 문서는 **MapleSchedule (메케줄) v1.0.6**의 주요 변경 사항을 핵심 위주로 간결하게 기록합니다.

---

### 1. 사이드바 [캐릭터 추가] 버튼 시인성 및 인터랙션 강화
- **버튼 및 아이콘 확대**: 세로 패딩(`py-3.5`), 텍스트 크기(`text-sm`), 칩 아이콘 박스(`w-6 h-6`) 및 `Plus` 아이콘 두께(`stroke-[2.5]`) 확대.
- **점선 테두리 강조**: 기본 점선 두께를 2px(`border-2 border-dashed`)로 굵게 변경.
- **마우스 호버 오렌지 글로우 효과**: 호버 시 테두리 오렌지(`border-orange-500`) 전환, 오렌지 네온 빛(`shadow-[0_0_18px_rgba(249,115,22,0.28)]`) 및 내부 아이콘 확대(`scale-110`) 적용.

---

### 2. UI 스크롤바 숨김 처리 (Clean Scroll View)
- **캐릭터 카드 목록 (`CharacterSidebar.tsx`)**: `no-scrollbar` 적용으로 스크롤 기능은 유지하면서 우측 스크롤바 막대만 숨김 처리.
- **진행 현황 패널 (`ProgressPanel.tsx`)**: `no-scrollbar` 적용으로 패널 우측 스크롤바를 숨겨 더욱 넓고 깔끔한 화면 구성.

---

### 3. 사이드바 계정 필터 구분선 제거
- **`CharacterSidebar.tsx`**: 상단 다계정(API) 필터 탭과 캐릭터 카드 목록 사이의 경계선(`border-b`)을 제거하여 끊김 없이 일체감 있는 사이드바 레이아웃 완성.

---

### 4. 상단 헤더 PiP 버튼 제거
- **`WindowHeader.tsx`**: 우측 설정 버튼 옆에 임시로 노출되던 `[PiP]` 버튼을 깔끔하게 제거하고, PiP 온/오프는 설정 모달에서만 단독 관리되도록 정돈.

---

### 5. 몬스터파크 월드별 클리어 합산 및 당일 API 공인 완료(One-Way) 보호 가드
- **월드별 분할 클리어 당일 누적 합산 (`monsterParkTracker.ts`)**:
  - 동일 계정(`apiKeyId`) 내에서 크로아 1회, 챌린저스 1회 등 월드를 나눠서 플레이해도 당일 월드별 횟수를 취합하여 합산 2회 달성 시 [완료]로 자동 판정.
- **당일 API 공인 완료 도장 및 유연한 수동 조작/새로고침 복구 지원 (`schedulerParser.ts`, `App.tsx`)**:
  - UI 상에서 사용자가 원할 경우 클릭으로 수동 체크해제(uncheck)가 가능하도록 유연하게 허용.
  - 수동으로 푼 상태에서 '새로고침(동기화)'을 누르면, 당일 API 공인 완료 도장 및 누적 횟수에 맞춰 인게임 팩트대로 다시 [완료]로 자동 복구.
  - 인게임에서 아직 클리어하지 않고 수동 체크만 해둔 상태라면, 새로고침 시 API 응답(0회)에 의해 실제 인게임 상태에 맞춰 자동으로 체크 해제되도록 완벽 연동.
- **다계정 독립 격리 및 타 컨텐츠(에픽던전/보스) 무영향 보장**:
  - 오직 몬스터파크(`daily_monster_park`)에만 정밀 격리 적용되어 다계정, 에픽던전, PiP, 일일/주간 보스에는 일절 사이드 이펙트 없이 안전하게 동작.

### 7. 모바일 웹 전용 버전 구현 (데스크톱 100% 무영향 보존)
- **하단 고정 네비게이션 바 (`MobileBottomNav.tsx`)**:
  - 모바일(화면 폭 `lg` 미만) 환경에서 화면 최하단에 3개 메인 버튼 추가: `[캐릭터]`, `[계정 컨텐츠]`, `[진행 현황]`.
  - 데스크톱(Electron 앱 및 PC 웹 브라우저)에서는 `lg:hidden`으로 완전히 숨겨져 기존 3단 레이아웃 100% 온전히 유지.
- **캐릭터 창 세로 터치 스크롤 최적화 (`CharacterSidebar.tsx`)**:
  - 모바일에서 캐릭터 카드가 많아도 아래에 가려지지 않고 손가락으로 부드럽게 위아래로 스크롤(`touch-pan-y`, `overscroll-contain`, `pb-28`)하여 끝까지 모든 카드를 확인 및 선택 가능.
  - 캐릭터 카드를 탭하면 해당 캐릭터의 일일/주간/보스 화면으로 자동 이동하며, 상단에 `[← 캐릭터 목록]` 복귀 버튼 제공.
- **계정 컨텐츠 및 진행 현황 모바일 탭 분기 (`ProgressPanel.tsx`)**:
  - `mobileMode`에 따라 `[계정 컨텐츠]` 탭에서는 몬스터파크/에픽던전 전용 뷰, `[진행 현황]` 탭에서는 달성률/통계 전용 뷰를 모바일 최적화로 제공.
- **모바일 화면 여백 및 UI 정리 (v1.0.6-mobile-patch)**:
  - 하단 불필요한 과도한 공백(더블 패딩)을 제거하여 모바일 스크롤이 네비게이션 바 바로 위까지 자연스럽고 타이트하게 이어지도록 최적화.
  - 모바일 `[계정 컨텐츠]` 탭 상단의 중복 헤더('계정 컨텐츠' 텍스트, 즐겨찾기 별표 버튼)를 깔끔하게 제거하여 몬스터파크와 에픽 던전이 맨 위부터 넓고 쾌적하게 보이도록 개선.
  - 모바일 캐릭터 상세 뷰에서 복잡하던 상단 탭 버튼(전체, 일일, 일보, 주간, 주보, 커스텀)을 숨기고, '스케줄 설정' 버튼을 캐릭터 이름 옆으로 콤팩트하게 이동하여 한 손 스크롤 가독성 극대화.

### 9. PiP 윈도우 토글 및 데스크톱 실행 동기화 오류 완전 해결
- **단일 진실 공급원(Single Source of Truth) 일원화**:
  - 기존에는 앱 실행 시 `window-state.json`에 남아있던 이전 열림 기록(`isOpen: true`)으로 인해 설정 토글이 꺼져 있어도 PiP 창이 강제로 실행되던 현상을 해결.
  - 앱 시작 시 실제 설정 데이터 파일(`storage.json`)의 `settings.pip.enabled` 값을 최우선으로 검증하도록 변경.
- **PiP 토글 명령 흐름 간소화 및 2중 트리거 차단**:
  - `SettingsModal`, `ProgressPanel`, `PiPFloatingWidget`에서 토글 시 `togglePiPWindow()`와 `onUpdateSettings()`가 동시에 호출되어 닫혔다 다시 열리는 현상을 제거하고 `handleUpdateSettings()`에서 명시적 `openPiPWindow()` / `closePiPWindow()`로 단일화.
  - `StandalonePiPView` 내에 설정 수신 시 `pip.enabled === false` 감지 시 즉시 자가 닫힘(Self-Closing) 안전 가드 추가.
- **버전 1.0.6 및 배포 exe 파일명 정식 지정 (`package.json`)**:
  - 설치형 실행 파일명: `메케줄 Setup 1.0.6.exe`
  - 무설치 포터블 파일명: `메케줄 1.0.6.exe`
  - `package.json`의 `artifactName` 및 `BUILD_INSTALLER_GUIDE.md` 동기화 완료.

### 10. 모바일 웹 브라우저 UI/UX 및 하단 여백 사용성 개선
- **모바일 브라우저 하단 메뉴바 가림 방지 여유 공간 확보**:
  - Safari, Chrome, 삼성 인터넷 등 모바일 브라우저의 동적 툴바/하단 탭바로 인해 화면 최하단 콘텐츠가 가려지지 않도록 `viewport-fit=cover` 설정 적용.
  - 메인 스케줄러 영역, 캐릭터 사이드바 목록, 계정 컨텐츠 및 진행 현황 패널의 하단 스크롤 여백에 `pb-[calc(env(safe-area-inset-bottom,0px)+5.5rem)]` 안전 영역을 적용하여 마지막 항목까지 완벽하게 스크롤 및 터치 조작 가능.
- **모바일 캐릭터 추가 시 원치 않는 자동 포커스 및 화면 확대 방지**:
  - `CharacterSearchModal` 진입 시 `autoFocus`를 제거하여 모바일에서 의도치 않게 키보드가 튀어나오거나 화면이 자동 확대(Zoom)되는 현상 방지.
  - 검색창 입력 폰트 크기를 모바일 16px(`text-base`)로 조정하여 모바일 OS(iOS 등)의 인풋 자동 확대 방지 기준 충족.

### 12. 모바일 스케줄 설정 모달 크기 반응형 최적화 및 퀘스트/보스 아이콘 원본 모서리 복원
- **모바일 스케줄 설정 창(`ContentConfigModal.tsx`) 화면 비율 반응형 최적화**:
  - **데스크톱 100% 원형 유지**: 데스크톱(`sm:` 이상) 환경에서는 기존 와이드 뷰 규격(`max-w-4xl`, `h-[720px]`, `max-h-[90vh]`)을 그대로 완벽하게 보존.
  - **모바일 환경 최적화**: 모바일(`sm:` 미만)에서 다른 모달들과 조화를 이루도록 `max-w-lg`, `h-[82dvh] max-h-[82dvh]`를 적용. 탭(검은 마법사, 커스텀, 일일/주간) 전환 시 컨텐츠 양에 따라 창 크기가 줄어들거나 들쑥날쑥 변하지 않고 일관된 고정 높이를 유지.
- **모바일 스케줄 설정 탭 네비게이션 바 상/하단 잘림 방지 (`ContentConfigModal.tsx`)**:
  - **데스크톱 100% 원형 유지**: 데스크톱(`sm:` 이상) 기존 클래스(`sm:pt-2.5`, `sm:pb-1`, `sm:py-0.5`, `sm:py-1.5`)는 일절 변경 없이 100% 동일하게 유지.
  - **모바일 전용 여백 최적화**: 색상이나 선을 일절 추가하지 않고, 모바일 탭 바 래퍼에 `pt-1 pb-3 sm:py-0.5` 및 버튼 패딩 `py-1.5 sm:py-1.5`를 적용하여 가로 스크롤 시 아래쪽 1px 테두리와 라운드가 0.1px도 잘리지 않고 온전히 노출되도록 개선.
- **퀘스트 및 보스 사진 모서리 잘림 수정 (원본 4각 복원)**:
  - `MapleIcon.tsx` 기본 클래스 및 퀘스트/보스 리스트(`DailyTaskList`, `DailyBossList`, `WeeklyTaskList`, `WeeklyBossList`, `BlackMageCard`, `ContentConfigModal`, `ProgressPanel`, `PiPOverlay`, `StandalonePiPView`) 전반에서 아이콘 이미지에 걸려있던 `rounded-xl` / `rounded-lg` 모서리 깎기 CSS 제거.
  - 메이플스토리 인게임 원본 보스 초상화 및 퀘스트/심볼 아이콘의 고유 테두리와 모서리 장식이 잘림 없이 온전하고 선명하게 100% 표시되도록 수정.
- **스케줄 설정 검은 마법사 난이도(하드/익스트림) 선택 시 텍스트 붉은색 강조 (`ContentConfigModal.tsx`)**:
  - 선택 시 난이도 라벨 텍스트 색상을 `text-red-500`으로 변경하여 블랙 배경/레드 테두리와 일체감 있는 시인성 확보.

### 14. 구글 애드센스 심사 통과를 위한 독립 하위 페이지 구축 및 콘텐츠 안전 가드
- **정식 독립 하위 페이지 신설 (`/guide`, `/terms`, `/privacy`)**:
  - **`/guide` (`GuidePage.tsx`)**: 메케줄 소개, 넥슨 Open API 핵심 규칙 3가지, 메이플스토리 리셋 주기표, 주간 보스 결정석 60개 최대 정산 전략, FAQ 6종, 로컬 보안 원칙 등 5,000자 이상의 고품질 정보성 오리지널 콘텐츠 탑재.
  - **`/terms`, `/privacy` (`LegalPage.tsx`)**: 서비스 이용약관 및 개인정보처리방침(제9조 온라인 맞춤형 광고/쿠키 및 구글 광고 설정 링크 포함)을 독립 웹 URL로 완벽하게 서빙.
- **웹/앱 듀얼 분기 스마트 라우팅 (`main.tsx`, `CharacterSidebar.tsx`)**:
  - **웹 브라우저 환경**: 표준 HTML `<a href="/guide">`, `<a href="/terms">`, `<a href="/privacy">` 링크로 구글 봇이 100% 탐색 및 크롤링할 수 있게 하고, 유저 클릭 시 새로고침 없는 매끄러운 SPA 라우팅 제공.
  - **데스크톱 Electron 앱 환경**: 기존 작업 흐름을 유지하도록 편리한 모달 팝업 형태 그대로 100% 원형 보존.
- **빈 화면 광고 송출 원천 차단 가드 (`AdSenseBanner.tsx`)**:
  - 캐릭터가 0명인 빈 화면이나 콘텐츠가 부족한 상태에서는 광고가 절대 송출되지 않도록 `hasContent` 가드를 적용하여 "게시자 콘텐츠가 없는 화면에 광고 게재" 위반 원천 방지.
  - 실제 숙제가 활성화된 화면 및 풍부한 텍스트가 있는 `/guide` 페이지에만 광고가 안전하게 게재되도록 설정.
- **메인 화면 캐릭터 미선택 뷰 100% 원형 유지 (`App.tsx`)**:
  - 기존 메인 화면의 심플하고 깔끔한 캐릭터 미선택 UI(로고, "선택된 캐릭터가 없습니다", [캐릭터 추가하기])를 그대로 완벽하게 보존.
  - 가이드, 약관, 개인정보처리방침 링크는 좌측 하단 푸터(`<a href="/guide">`, `<a href="/terms">`, `<a href="/privacy">`)에 정식 배치하여 메인 UI를 깨끗하게 유지.

  - `public/robots.txt` 및 `public/sitemap.xml` 생성 (하위 페이지 전체 등록).
