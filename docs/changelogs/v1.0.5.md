# 🚀 메케줄 v1.0.5 업데이트 상세 내역 (docs/changelogs/v1.0.5.md)

이 문서는 **MapleSchedule (메케줄) v1.0.5** 버전에서 진행된 주요 기능 추가, 버그 수정, 아키텍처 개선 및 UI/UX 모션 고도화 내역을 상세히 기록합니다.

---

### 1. PiP 및 토글 스위치, 계정 전환 모션 애니메이션 고도화
1. **스위치 토글 버튼 스프링 애니메이션 (`SwitchToggle.tsx`, `ProgressPanel.tsx`, `SettingsModal.tsx`)**:
   - `motion/react` 기반의 물리 스프링 애니메이션(`type: 'spring', stiffness: 550, damping: 32`)을 탑재한 공용 `SwitchToggle` 컴포넌트 구현.
   - 메인 화면 PiP 토글 및 설정 모달 내 모든 스위치(다크 모드, PiP 옵션, 초기화 알리미, 윈도우 시작 시 자동 실행 등)에 일괄 적용.
2. **웹 & 데스크톱 PiP 카드 표시/숨김 부드러운 애니메이션 (`PiPOverlay.tsx`, `StandalonePiPView.tsx`)**:
   - `AnimatePresence (popLayout)`와 `motion.div`를 결합하여 캐릭터 카드의 표시/숨김, 완료 숨김 필터링, 정렬 변경 시 부드러운 scale / opacity / y축 모션(`stiffness: 460, damping: 28`) 적용.
   - 인접 카드들이 `layout` 속성을 통해 자연스럽게 자리를 이동하여 극도로 매끄러운 사용자 경험 실현.
3. **계정 전환 및 별칭 필 탭 모션 고도화 (`AccountIndicatorBar.tsx`, `ProgressPanel.tsx`)**:
   - 다계정 환경에서 활성 계정이 변경될 때 계정 인디케이터 점 ➔ 별칭 필(Pill)로 확장되는 트랜지션에 스프링 레이아웃 모션 적용.
   - 계정 컨텐츠 패널 전환 시 `AnimatePresence`를 통해 부드러운 페이드/슬라이드 전환 연출.

### 2. API 키 추가/삭제/별칭 수정 즉각(0ms) 실시간 동기화
1. **배경**: 기존에는 API 키 관리 모달에서 API 키를 새로 추가하거나, 삭제하거나, 별칭(닉네임)을 수정했을 때 화면에 즉시 반영되지 않아 사용자가 수동 새로고침(F5)을 해야 했던 문제 해결.
2. **전역 동기화 파이프라인 (`syncChannel.ts`, `ApiKeyModal.tsx`, `App.tsx`, `ProgressPanel.tsx`, `PiPOverlay.tsx`, `StandalonePiPView.tsx`)**:
   - `CustomEvent('mapleschedule:apikeys-updated')`를 통해 동일 브라우저 윈도우 내의 모든 컴포넌트에 0ms 즉각 이벤트 전파.
   - `BroadcastChannel`을 통해 Electron 독립 PiP 윈도우 및 다중 브라우저 창까지 실시간 동기화.
   - `ApiKeyModal.tsx`에서 키 등록(`handleAddKey`), 별칭 수정(`handleSaveEdit`), 키 삭제(`handleDeleteKey`) 완료 즉시 최신 키 목록을 브로드캐스트.
3. **메인 화면 및 컴포넌트 실시간 반응**:
   - `App.tsx`: `apiKeys` 최상위 상태 관리 및 `subscribeToApiKeys` 연동. 키 목록 변경 즉시 `hasApiKey` 및 `apiKeys` 갱신. 별칭 변경 시 등록된 캐릭터들의 `apiKeyAlias` 매핑까지 실시간 갱신하여 캐릭터 카드 태그에 즉각 반영.
   - `ProgressPanel.tsx`: '계정 컨텐츠' 별칭 필 바가 새로고침 없이 0ms 즉각 추가/삭제/이름 변경되어 재렌더링.
   - `PiPOverlay.tsx` & `StandalonePiPView.tsx`: PiP 오버레이 및 Electron 독립 PiP의 계정 인디케이터 점과 별칭 태그가 실시간으로 동기화.

### 3. 메인 화면 계정 컨텐츠 다계정 별칭 바 및 가로 스크롤
1. **다계정 등록 시 노출**: 복수 개의 API 키가 등록된 환경(`accountIndicatorItems.length >= 2`)에서 '계정 컨텐츠' 헤더 바로 아래 줄에 등록된 API 키 별칭들이 필(Pill) 탭 형태로 노출.
2. **등록 순서 정렬**: `buildAccountIndicatorItems`를 통해 등록된 순서대로 정렬되어 일관된 사용자 경험 제공.
3. **원클릭 계정 전환**:
   - 별칭 탭 클릭 시 해당 API 키의 계정 컨텐츠(몬스터파크, 에픽 던전 등) 클리어 현황이 즉시 화면에 표시.
   - 활성 캐릭터 전환 시 기본 계정이 자동으로 동기화되며, 수동 탭 클릭으로 자유롭게 다른 계정 진행도 확인 가능.
   - 몬스터파크 및 에픽 던전 클릭 토글 시에도 현재 선택된 API 계정(`effectiveApiKeyId`)으로 독립 격리 처리.
4. **가로 스크롤 및 마우스 휠 지원**: 계정 목록이 길어질 경우 줄바꿈 없이 가로로 스크롤되며 마우스 휠(`onWheel`) 가로 이동 지원.

### 7. 월드리프(서버 이전) 캐릭터 자동 치유 (Self-Healing)
1. **배경**: 메이플스토리 인게임에서 캐릭터가 월드리프(월드 이동)를 진행하면 기존 `ocid`가 만료되어 넥슨 Open API 조회 시 `400 Bad Request` 에러가 발생하는 문제 해결.
2. **해결 방식**:
   - 백엔드(`/api/nexon/character/...`) 및 웹 클라이언트(`fetchCharacterBasic`, `fetchNexonSchedulerState`): 기존 OCID 조회가 실패할 경우 캐릭터명(`name`)으로 넥슨 `/id?character_name=...`를 호출하여 새 `ocid`를 즉시 재발급받은 뒤 데이터 복구.
   - 프론트엔드(`App.tsx`): 캐릭터 고유 키(`char.id`)는 그대로 유지하면서 `char.ocid`, `char.worldName`, `char.characterImage` 등을 실시간 갱신하여 기존 체크 내역 100% 보존.

### 10. 캐릭터 선택 시 계정 컨텐츠 동기화, 메인 카드 스프링 모션, API 삭제/재연결 자동 정리
1. **캐릭터 선택 시 계정 컨텐츠(API) 즉시 동기화 (`ProgressPanel.tsx`, `App.tsx`)**:
   - 계정 컨텐츠에서 수동으로 다른 계정을 둘러본 후, 좌측 목록에서 특정 캐릭터를 클릭하면 해당 캐릭터가 소속된 API 계정 컨텐츠로 즉시 자동 전환되도록 동기화 트리거(`characterSelectTrigger`) 및 상태 갱신 로직 적용.
2. **메인 화면 캐릭터 카드 위치 변경 스프링 모션 (`CharacterSidebar.tsx`)**:
   - PiP 오버레이와 동일한 `motion/react` 기반의 물리 스프링 애니메이션(`layout`, `type: 'spring', stiffness: 460, damping: 28`) 및 `AnimatePresence (popLayout)` 탑재.

3. **API 키 삭제 시 별칭 즉시 제거 및 재연결 자동 링크 (`accountHelper.ts`, `App.tsx`, `ProgressPanel.tsx`)**:
   - `buildAccountIndicatorItems`에서 유효하지 않은(삭제된) API 키가 남아 유령 계정 탭이 유지되던 문제를 원천 차단하고, 등록된 API 키가 2개 미만일 시 별칭 바가 즉시 사라지도록 최적화.
   - API 키 삭제 시 캐릭터의 `apiKeyId`를 안전하게 정리하고, API 키를 다시 연결하거나 1개의 키만 남았을 때 기존 캐릭터들이 해당 키에 즉시 자동으로 재연결되도록 처리.

### 11. 중앙 리스트 접고 펼치기 실키 모션 및 화살표 180° 회전 애니메이션
1. **적용 대상**: `DailyTaskList.tsx`, `DailyBossList.tsx`, `WeeklyTaskList.tsx`, `WeeklyBossList.tsx`, `CustomTaskList.tsx` (5개 섹션 전체)
2. **화살표(Chevron) 180° 회전 모션**:
   - 기존 아이콘 순간 교체(`ChevronDown` ↔ `ChevronUp`) 방식을 탈피하고, `motion.div`를 통한 부드러운 180도 회전 애니메이션(`duration: 0.32, ease: [0.16, 1, 0.3, 1]`) 적용.
3. **실키한 곡선(Cubic-Bezier) 높이 조절 및 미세 Y축 슬라이드 결합**:
   - 높이 애니메이션 시간을 0.35초로 부드럽게 조정하고 iOS/macOS 스타일의 고급 감속 곡선(`[0.16, 1, 0.3, 1]`) 적용.
   - 내부 내용물에 미세 Y축 이동(`y: -8px ➔ 0px`) 및 페이드인/아웃을 결합하여 스르륵 열리고 닫히는 입체적이고 극도로 부드러운 모션 완성.

   - `motion` 기반 스프링 선택 필(Pill) 애니메이션 및 클릭 전환 인터랙션은 그대로 유지.

### 13. 계정 컨텐츠 목록 API(계정)별 독립 설정 및 PiP 완벽 반영 (`commonContents.ts`, `ProgressPanel.tsx`, `PiPOverlay.tsx`, `StandalonePiPView.tsx`, `syncChannel.ts`)
1. **API별 독립 저장 구조화**:
   - 기존 전역 단일 배열(`string[]`) 형태에서 API별 키 매핑(`Record<string, string[]>`) 구조로 고도화 (하위 호환 100% 지원).
   - 각 계정(API)마다 몬스터파크, 에픽 던전(하이마운틴, 앵글러컴퍼니, 악몽의 유적 등) 활성화/비활성화 항목을 다르게 설정 가능.
2. **계정 컨텐츠 편집 창(`ProgressPanel.tsx`) 내 API 별칭 탭 구현**:
   - 복수 API 등록 시, 모달 상단에 '편집할 계정(API) 선택' 탭 목록(줄바꿈 지원) 노출.
   - 탭을 클릭하여 각 계정별로 원하는 컨텐츠만 체크/해제 가능하며 즉각 저장.
3. **메인 화면 및 통계 연동**:
   - 현재 선택된 계정(`effectiveApiKeyId`)에 설정된 계정 컨텐츠 항목만 화면에 표시 및 진행률 통계에 실시간 반영.
4. **웹/데스크톱 PiP 실시간 연동 (`PiPOverlay.tsx`, `StandalonePiPView.tsx`)**:
   - PiP 창에서도 현재 활성화된 캐릭터의 소속 계정(API)에 지정된 계정 컨텐츠 목록만 정확히 산출하여 렌더링.
   - 메인 화면에서 설정을 변경하는 즉시 `BroadcastChannel` 및 `CustomEvent`를 통해 0ms 즉각 동기화 반영.
5. **캐릭터 등록 계정 한정 노출 가드 (`accountHelper.ts`)**:
   - API 키만 등록되고 캐릭터가 0명인 빈 계정은 계정 컨텐츠 선택 탭, 편집 모달 탭 및 계정 전환 인디케이터에서 자동 제외.
   - 해당 API 키에 캐릭터가 1명 이상 등록되는 순간 즉시 계정 컨텐츠 및 전환 탭이 활성화되어 불필요한 빈 껍데기 UI 노출 방지.
6. **사이드바 소속 계정 뱃지 및 다계정 필터 (`CharacterSidebar.tsx`)**:
   - 다계정(2개 이상 유효 계정) 환경 시, 각 캐릭터 카드에 해당 캐릭터의 소속 계정 별칭 칩(`[계정 1]`, `[본계정]` 등)을 은은하게 표시하여 직관적인 식별 지원.
   - 사이드바 상단 '캐릭터 추가' 버튼 아래에 계정별 미니 필터 탭(`전체`, `계정 1`, `계정 2`...)을 제공하여 원하는 계정의 캐릭터만 빠르게 모아보기 가능.
7. **계정 컨텐츠 편집 창 UI 정돈 (`ProgressPanel.tsx`)**:

   - 탭 영역의 하단 분리선 및 이질적인 배경색을 모달 배경과 일치하도록 자연스럽고 모던하게 정돈.

### 15. API 키 삭제 시 연동 캐릭터 및 기록 일괄 연쇄 삭제 (Cascading Deletion)
1. **배경**: 기존에는 API 키를 삭제해도 기존 캐릭터 카드가 고아(Orphan) 상태로 남아있어, 이후 API 키를 새로 추가했을 때 뱃지가 표시되지 않거나 계정 공통 컨텐츠 탭에 정상적으로 편입되지 않던 문제를 원천 해결.
2. **연쇄 삭제 동작 (`App.tsx`, `ApiKeyModal.tsx`, `commonContents.ts`)**:
   - **전체 삭제**: 등록된 모든 API 키가 삭제(0개)되는 경우, 등록된 모든 캐릭터, 진행도 기록(`records`), 활성 캐릭터 상태 및 계정 컨텐츠 설정을 완전히 일괄 삭제(`[]`, `{}`)하여 깨끗한 상태로 리셋.
   - **선택 삭제**: 복수 계정 중 특정 API 키가 삭제되는 경우, 해당 API 키(`apiKeyId`)에 연결되어 있던 캐릭터들만 정확하게 연쇄 삭제(`filter`) 처리.
   - **진행도 및 활성 캐릭터 자동 정리**: 삭제된 캐릭터의 일일/주간/보스 체크 진행도 레코드를 즉시 청소하고, 현재 선택된 활성 캐릭터가 삭제 대상인 경우 남아있는 첫 번째 캐릭터로 자동 전환.
   - **계정 맞춤 설정 정리**: 삭제된 API 키의 계정 공통 컨텐츠 설정(`mapleschedule_common_content_ids`) 키값 자동 정리 및 브로드캐스트.
3. **UI 안내 문구 고도화 (`ApiKeyModal.tsx`)**:
   - API 키 삭제 시 "연동 캐릭터도 삭제됩니다. 계속할까요?" 인라인 확인 문구 노출로 사용자 인지성 강화.
   - 삭제 완료 시 "API 키와 연동된 캐릭터가 모두 삭제되었습니다." 안내.

### 16. API 키 정보(별칭 및 API 키) 수정 및 넥슨 API 사전 유효성 검증 가드 (Safe Key Update)
1. **배경**:
   - API 키 갱신/재발급 시 기존 키를 삭제했다가 다시 추가하면 연동된 캐릭터가 함께 삭제되는 파괴적 손실을 방지하고, 키의 고유 ID를 유지한 채 키 값만 안전하게 갱신할 수 있도록 지원.
2. **인라인 수정 UI 확장 (`ApiKeyModal.tsx`)**:
   - 기존 별칭(닉네임)만 수정 가능하던 구조에서, 계정 별칭과 `NEXON Open API Key` 문자열을 모두 수정할 수 있는 전용 인라인 폼 제공.
3. **3중 안전 가드 (Pre-Validation Guard)**:
   - **사전 유효성 검증**: 사용자가 새 API 키를 입력하고 [검증 후 저장] 클릭 시, 넥슨 Open API에 먼저 유효성 테스트 핑을 발송.
   - **기존 데이터 100% 보호**: 오타나 만료 등으로 검증에 실패할 경우, 에러 메시지를 표시하며 기존 API 키와 연동 캐릭터를 원본 상태 그대로 유지.
   - **정상 통과 시 안전 갱신**: 넥슨 인증 성공 시에만 기존 계정 ID를 유지한 채 키 값을 갱신하여, 캐릭터 연동과 체크 기록이 1초의 단절 없이 그대로 유지됨.
4. **듀얼 플랫폼 지원**:
   - 데스크톱/서버 환경(`server.ts`의 `PUT /api/nexon/keys/:id`)과 웹 브라우저 로컬 스토리지 환경(`src/services/api.ts`의 `updateApiKey`) 양쪽 모두 100% 동일하게 지원.
5. **오타 및 무효 키 HTTP 400 필터링 보강 (Bugfix)**:
   - 넥슨 Open API가 잘못된 키에 대해 HTTP 400 (`OPENAPI00005: The apikey is not valid.`)을 반환할 때 기존에 401/403만 검사하여 오타 키가 통과되던 취약점을 전면 해결.
   - `!res.ok` 및 넥슨 에러 응답 전체를 검사하여 오타나 무효 키 입력 시 즉각 저장을 차단하고 기존 데이터를 안전하게 보호하도록 보강.

### 17. API 키 입력 즉시 규격 검사(공백 자동제거) 및 화면 공유/방송용 마스킹 토글 (Input Sanitization & Masking Toggle)
1. **공백 자동 제거 (Auto-Trim on Input)**:
   - 신규 API 키 등록 및 기존 키 수정 시, 복사/붙여넣기 과정에서 빈번히 유입되는 앞뒤 공백 및 줄바꿈 문자를 입력 즉시 `e.target.value.trim()`으로 자동 제거하여 오입력 원천 차단.
2. **실시간 넥슨 Open API 규격 검사 인디케이터**:
   - 사용자가 키를 입력하는 즉시 `live_` 또는 `test_` 접두사 및 길이 규격을 실시간으로 판별.
   - 규격에 맞지 않는 문자열 입력 시 안내 메시지(`"넥슨 API 키는 일반적으로 'live_'로 시작합니다..."`)를 즉각 노출하여 검증 전 빠른 수정 유도.
   - 정상 규격 입력 시 초록색 체크 인디케이터(`"넥슨 Open API 규격(live_...)과 일치합니다."`) 노출.
3. **화면 공유 및 방송 보호용 마스킹 토글 (`ApiKeyModal.tsx`)**:
   - **기본 마스킹 보호**: 등록된 API 키 카드에서 키의 중간부를 `live_••••••••••••••••xxxx` 형태로 안전하게 마스킹하여 디스코드 화면 공유나 인터넷 방송 중 API 키 탈취를 방지.
   - **눈 모양(Eye/EyeOff) 토글 아이콘**: 각 키 항목 우측에 토글 버튼을 제공하여 필요 시 원클릭으로 실제 키를 확인하거나 다시 숨길 수 있도록 지원.
   - **수정 폼 마스킹 보호**: 수정 모드에서도 패스워드 마스킹 및 눈 모양 토글 버튼을 제공하여 안전한 편집 환경 구축.
   - **완전한 키 복사 지원**: 마스킹 상태 여부와 관계없이 [복사] 버튼 클릭 시에는 항상 전체 원본 API 키가 클립보드에 정확하게 복사됨.

### 18. 신규 API 키 등록 시 사전 유효성 검증 적용 (Pre-Validation Guard on Add)
1. **배경**: 기존에는 API 키 수정 시에만 사전 검증이 작동하여, 신규 키 등록 시 오타가 있거나 만료된 키를 입력해도 그대로 저장되어 캐릭터 추가 모달이나 스케줄러 동기화 시 오류가 발생하던 문제 해결.
2. **검증 메커니즘 (`ApiKeyModal.tsx`의 `handleAddKey`)**:
   - [검증 후 API 등록] 클릭 시 넥슨 Open API에 먼저 유효성 테스트 핑(`testApiKey`)을 발송.
   - 오타나 비정상 키일 경우 저장 절차를 즉시 중단하고 명확한 에러 메시지(`[API 키 검증 실패] 넥슨에 등록되지 않았거나 오타가 있는 API 키입니다.`)를 출력.
   - 검증 진행 중 버튼 내 회전 스피너와 `"API 키 검증 및 등록 중..."` 문구를 표시하여 사용자에게 실시간 상태 피드백 제공.
