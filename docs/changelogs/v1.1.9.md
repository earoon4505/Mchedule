## 🚀 넥슨 Open API & 메이플스토리 점검 배너 통합 및 신뢰성 개선

### 1. 점검 배너 단일 통합 (사용자 승인 반영)
- **배경 및 원인 분석**:
  - 메이플스토리 인게임 점검(통상 03:00~10:00)과 넥슨 Open API 점검(통상 07:00~13:00)의 종료 시점이 서로 다름.
  - 인게임 접속이 가능해진 후에도 넥슨 API 내부 DB 동기화가 진행 중일 때 넥슨 서버가 여전히 `OPENAPI00010`("게임 점검 중")을 반환하여 인게임 접속 중인 유저에게 혼란을 유발함.
- **조치 사항**:
  - 점검 배너 체계를 하나로 명쾌하게 통합:
    - **테마 색상**: 빨간색 (Red) 테마 (`bg-gradient-to-r from-red-500/15 via-rose-500/10 to-red-500/15 border-red-500/30`)
    - **배지**: **`[점검 중]`** (`bg-red-500/20 text-red-700 dark:text-red-300 border border-red-500/30`)
    - **메인 문구**: **`메이플스토리 or 넥슨 OPEN API 점검 중`**
    - **오류 코드 칩**: 실제 넥슨 응답 코드(`OPENAPI00010`, `OPENAPI00011`, `OPENAPI00001`, `HTTP 503` 등)를 그대로 표기하여 투명성 보장.
    - **문구 및 버튼 구성**: 불필요한 시각적 요소를 줄이고 심플하고 직관적인 구성을 위해 긴 부가설명 문구 및 '상태 재확인' 버튼을 제거하고, 핵심 타이틀과 안내 닫기(X) 버튼만 유지.

### 2. 백엔드 및 클라이언트 에러 처리 동기화
- `src/App.tsx`, `src/services/api.ts`, `server.ts` 전반에 걸쳐 점검 알림 및 토스트 메시지를 `메이플스토리 or 넥슨 OPEN API 점검 중`으로 일치화.
- 데스크톱 Electron 및 웹 듀얼 환경 모두에서 100% 동일한 안정성 보장.
