# 🍁 메케줄(MapleSchedule) v1.2.1 릴리즈 노트

**배포 일자**: 2026년 10월 27일  
**적용 대상**: Windows 데스크톱 앱 (Electron) 및 공식 웹 애플리케이션

## 📌 주요 업데이트 요약

### 1. 🔒 보안 강화 및 미사용 레거시 잔재 완전 정리
* **레거시 비공개 명세 및 잔재 파일 완전 제거**:
  - 더 이상 지원하지 않는 레거시 기능 및 명세 문서, 미사용 임시 데이터 파일 등을 저장소에서 완전히 영구 삭제하였습니다.
  - 공개 저장소 및 외부 노출 리스크를 원천 차단하여 코드 무결성과 보안을 한층 강화했습니다.
* **타입 정의 및 빌드 스크립트 클린업**:
  - `src/types/index.ts` 내 미사용 전역 플래그 및 레거시 인터페이스를 완벽히 도려내어 번들 크기와 컴파일 순도를 최적화했습니다.
  - 빌드 전처리 스크립트(`scripts/prepare-build.cjs`, `scripts/build-web.cjs`, `scripts/build-desktop.cjs`)에서 불필요한 동기화 구문과 오래된 주석을 정리하였습니다.

### 2. ⚡ 시스템 안정성 및 최적화
* **보스 카드 스펙 연산 안정화**:
  - `BossScheduleCard.tsx`에서 캐릭터 포스 수치 참조 로직을 표준 필드 우선으로 정리하여 넥슨 공식 인게임 수치 계산 정확도를 한층 더 높였습니다.
* **버전 동기화 (v1.2.1)**:
  - 데스크톱 앱 자동 업데이트, 패키지 메타데이터, 애플리케이션 환경 전체를 v1.2.1로 단일화하여 일관된 릴리즈 라이프사이클을 보장합니다.
