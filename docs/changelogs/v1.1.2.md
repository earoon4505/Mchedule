# 🚀 메케줄 v1.1.2 업데이트 내역 (docs/changelogs/v1.1.2.md)

이 문서는 **MapleSchedule (메케줄) v1.1.2**의 주요 변경 사항 및 작업 내역을 명확하게 기록합니다.

---

## 📌 v1.1.2 마일스톤 (2026년 10월)

### 1. 자동 업데이트 다운로드 및 배포 파이프라인 실전 검증
1. **GitHub Releases 자동 업데이트 규격 검증**:
   - v1.1.1에서 도입된 깃허브 릴리즈 배포 규격(`${name}-setup-${version}.${ext}`) 및 `latest.yml` 해시 매칭 체계의 실시간 업데이트 다운로드 파이프라인 검증.
   - 기존 v1.1.1 클라이언트 사용자가 앱 실행 시 백그라운드에서 신규 `v1.1.2` 릴리즈를 정상 감지하고 자동 다운로드 후 업데이트 팝업(`UpdateModal`)을 띄우는지 테스트하기 위한 릴리즈 버전 판올림.
2. **버전 상수 및 아티팩트 동기화**:
   - `package.json`: 버전 `1.1.1` ➔ `1.1.2` 갱신.
   - `src/constants/version.ts`: `APP_VERSION = '1.1.2'` 단일 진실 소스 동기화.
   - `src/App.tsx`: 자동 업데이트 리스너 기본 버전 폴백 동기화.
   - `BUILD_INSTALLER_GUIDE.md`: `maple-schedule-setup-1.1.2.exe` 및 `메케줄 1.1.2.exe` 배포 안내 동기화.
