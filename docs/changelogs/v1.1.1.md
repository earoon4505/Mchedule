# 🚀 메케줄 v1.1.1 업데이트 내역 (docs/changelogs/v1.1.1.md)

이 문서는 **MapleSchedule (메케줄) v1.1.1**의 주요 변경 사항 및 작업 내역을 핵심 위주로 명확하게 기록합니다.

---

## 📌 v1.1.1 마일스톤 (2026년 10월)

### 1. 사용자 주도 업데이트 및 인앱 안내 팝업 도입
1. **강제 자동 설치 방지 및 사용자 승인형 전환**:
   - 기존의 앱 종료 시 자동 강제 설치(`autoInstallOnAppQuit = true`)를 해제(`autoInstallOnAppQuit = false`)하고, 오직 사용자가 직접 **[업데이트]** 버튼을 클릭해야만 즉시 재실행 및 패치(`quitAndInstall()`)가 진행되도록 제어 정책 개선.
2. **신규 업데이트 안내 모달 (`src/components/common/UpdateModal.tsx`)**:
   - 새 버전 다운로드 완료 시 화면 중앙에 직관적인 팝업 표시:
     > **메케줄 (v {version}) 업데이트가 준비되었습니다.**  
     > **지금 바로 업데이트를 진행하시겠습니까?**
   - **[나중에 하기]** 버튼: 작업 중인 게임이나 스케줄러 흐름을 방해하지 않고 팝업을 닫으며, 다음번에 앱을 다시 실행했을 때 안내가 다시 표시됨.
   - **[업데이트]** 버튼: 즉시 앱을 재실행하여 1초 만에 새 버전으로 안전하게 교체 설치.
3. **상단 타이틀바 [업데이트] 포인트 버튼 신설 (`WindowHeader.tsx`)**:
   - 업데이트가 다운로드되어 준비 완료되면, 상단 우측 공지사항(확성기) 버튼 왼쪽에 눈에 띄는 **[업데이트]** 버튼 노출.
   - '나중에 하기'로 팝업을 닫았더라도 언제든지 이 버튼을 클릭하여 업데이트 팝업을 다시 열고 즉시 설치 가능.

### 2. 깃허브 자동 업데이트 규격 및 파일명 완전 일치화
- **`package.json`**:
  - `win.artifactName`을 `${name}-setup-${version}.${ext}`로 통일하여 빌드 산출물(`maple-schedule-setup-1.1.1.exe`)과 `latest.yml`의 URL이 100% 일치하도록 수정, 404 다운로드 차단 오류를 원천 방지.
  - 앱 버전 `1.1.0` ➔ `1.1.1` 판올림.
- **`src/constants/version.ts`**:
  - 전역 앱 버전 상수 `APP_VERSION = '1.1.1'` 동기화.
- **`BUILD_INSTALLER_GUIDE.md`**:
  - 1.1.1 인스톨러 및 포터블 파일명 갱신.

### 3. 데스크톱 IPC 파이프라인 확장
- **`electron/preload.cjs` & `electron/main.cjs`**:
  - `quitAndInstall`, `onUpdateDownloaded`, `checkForUpdateStatus` IPC 채널 등록.
  - 메인 윈도우 로드 완료(`did-finish-load`) 시점에 다운로드 완료된 업데이트 상태를 감지하여 렌더러로 안전하게 이벤트 재전송.
