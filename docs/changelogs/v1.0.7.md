## 📌 v1.0.7 마일스톤 (2026년 10월)

- **`package.json`**: 앱 버전 `1.0.6` ➔ `1.0.7` 판올림
- **`metadata.json`**: 앱 명칭 `메케줄 1.0.7` 동기화
- **`BUILD_INSTALLER_GUIDE.md`**: Windows 설치형(`메케줄 Setup 1.0.7.exe`) 및 무설치 포터블(`메케줄 1.0.7.exe`) 빌드 명세 갱신
- **`AGENTS.md`**: 세부 문서 체계에 `v1.0.7.md` 신규 등록 및 15KB 상한 보존

### 2. 주간 보스 결정석 가격 및 신규 익스트림 난이도 반영 (`src/data/defaultTasks.ts`)
1. **익스트림 카링 결정석 가격 변경**:
   - `boss_extreme_kaling`: 기존 53억 8,700만 메소 ➔ **48억 4,500만 메소** (`4,845,000,000`)
2. **익스트림 유피테르 결정석 가격 변경**:
   - `boss_extreme_jupiter`: 기존 48억 4,500만 메소 ➔ **53억 8,700만 메소** (`5,387,000,000`)
   - 이전 버전 `boss_hard_jupiter` 기록과의 100% 하위 호환성 유지 (자동 승격 및 `ALL_TASKS_MAP` 안전 매핑)
3. **주간 보스 리스트 익스트림 림보 신규 추가**:
   - `boss_extreme_limbo`: **75억 메소** (`7,500,000,000`), 난이도 라벨 '익스트림'
4. **주간 보스 리스트 익스트림 발드릭스 신규 추가**:
   - `boss_extreme_valdrix`: **96억 메소** (`9,600,000,000`), 난이도 라벨 '익스트림'

### 3. 아이콘 매핑 및 넥슨 API 스케줄러 동기화 고도화
- **`MapleIcon.tsx`**: `boss_extreme_limbo`, `boss_extreme_valdrix`, `boss_extreme_jupiter` 아이콘 매핑 등록
- **`schedulerParser.ts`**:
  - `sortBossIdsByStandardOrder`: `boss_hard_jupiter` ➔ `boss_extreme_jupiter` 무손실 자동 정규화
  - `findBossGroupInfo`: 유피테르 인게임 클리어 시 API 응답 난이도(하드/익스트림) 유연 매칭 지원

### 4. GitHub Actions 완전 자동 배포 (Push-to-Release) 및 데스크톱 자동 업데이트 (`.github/workflows/build-desktop.yml`)
1. **푸시만 하면 끝나는 무설정 전자동 릴리즈 (Push-to-Release)**:
   - 사용자가 `package.json`의 `"version"`을 올리고 `main` 브랜치에 `git push`만 하면, 깃허브 웹사이트에 들어갈 필요 없이 GitHub Actions가 자동으로 버전을 감지 (`Extract App Version`).
   - Windows 가상머신(`windows-latest`)에서 최신 설치형(`.exe`) 및 포터블(`.exe`)을 빌드(`npm run dist`).
   - GitHub Releases에 `v${APP_VERSION}` 태그 및 릴리즈를 자동 생성하고 인스톨러, `latest.yml`, `.blockmap`을 일괄 배포.
2. **기존 설치 앱 자동 업데이트(AutoUpdater) 연동**:
   - `electron/main.cjs`의 `electron-updater` 모듈을 통해 사용자가 앱을 실행할 때 5초 후 백그라운드에서 새 버전을 자동 감지.
   - 공개(Public) GitHub 저장소의 Releases와 연동되어 별도 토큰이나 조작 없이 무중단 자동 다운로드 및 앱 종료 시 자동 패치 완벽 지원.
