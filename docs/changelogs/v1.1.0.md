# 🚀 메케줄 v1.1.0 업데이트 내역 (docs/changelogs/v1.1.0.md)

이 문서는 **MapleSchedule (메케줄) v1.1.0**의 주요 변경 사항 및 작업 내역을 핵심 위주로 명확하게 기록합니다.

---

## 📌 v1.1.0 마일스톤 (2026년 10월)

### 1. 버전 식별자 및 단일 소스 버전 관리 체계 구축
- **`src/constants/version.ts` 신설**:
  - `APP_VERSION = '1.1.0'` 상수를 정의하여 앱 전역에서 버전을 단일 소스(Single Source of Truth)로 안전하게 참조하도록 설계.
- **`package.json`**: 앱 버전 `1.0.7` ➔ `1.1.0` 정식 판올림.
- **`metadata.json`**: 앱 명칭 `메케줄 1.1.0` 유지 및 동기화.
- **`BUILD_INSTALLER_GUIDE.md`**: Windows 설치형(`메케줄 Setup 1.1.0.exe`) 및 무설치 포터블(`메케줄 1.1.0.exe`) 빌드 명세 갱신.

### 2. 설정 모달 (SettingsModal) 버전 표기 및 UI 개선
1. **모달 상단 헤더 버전 뱃지 추가**:
   - '설정' 타이틀 바로 옆에 오렌지 톤의 미니 뱃지(`v1.1.0`)를 배치하여 앱의 현재 빌드 버전을 즉시 인지할 수 있도록 개선.
2. **모달 상단 헤더 닫기(✕) 버튼 추가**:
   - 기존 하단 '닫기' 버튼 외에 헤더 우측 상단에도 직관적인 닫기 버튼을 추가하여 조작 편의성 증대.
3. **모달 하단 정보 푸터 버전 명시**:
   - 운영 정책 및 라이선스 안내 영역에 `메케줄 v1.1.0`을 공식 표기.

### 3. GitHub Actions 데스크톱 자동 빌드 워크플로우 안정화
- **`.github/workflows/build-desktop.yml`**:
  - `npm ci`의 lockfile 버전 충돌 에러 방지를 위해 `npm install` 및 `electron`, `electron-builder` 사전 설치 파이프라인으로 개선.
  - Tailwind CSS v4(`lightningcss-win32-x64-msvc`) 및 Rollup(`@rollup/rollup-win32-x64-msvc`)의 Windows 플랫폼 네이티브 바이너리 누락 버그(npm optionalDependencies 버그) 완벽 해결.
  - `package.json`의 NSIS 인스톨러 명칭(`artifactName`)을 `${name}-setup-${version}.${ext}`로 통일하여 `latest.yml`과 100% 일치시켜 404 다운로드 오류 영구 해결.
  - Windows 가상머신 환경에서 설치형(`.exe`), 포터블(`.exe`), `latest.yml` 릴리즈 자동 배포가 중단 없이 원활히 진행되도록 강화.

### 4. 웹 소스코드 보안 및 외부 노출 차단 강화
- **`src/components/settings/SettingsModal.tsx`**:
  - 웹 번들 분석을 통한 깃허브 저장소 주소 및 계정명 추적을 원천 차단하기 위해, 다운로드 관련 로직 및 깃허브 API 호출 주소(`earoon4505/Mchedule-exe-file`)를 완전 제거.
  - 외부인이 웹사이트 개발자 도구(F12)나 자바스크립트 번들을 분석하더라도 작성자의 깃허브 저장소 주소를 일절 알아낼 수 없도록 보안 조치 완료.
